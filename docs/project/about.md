## Related projects

[django-cc-sightline](https://django-cc-sightline.readthedocs.io) adds click heatmaps, scroll maps and session replay to a Django site, with its own panel inside the admin. The two packages work well together: sightline's panel picks up the django-cc-admin theme like any other admin page.
